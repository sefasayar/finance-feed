Privacy Policy

Finance Feed does not ask for accounts, does not set cookies and does not run analytics or advertising at the moment.

Last updated: November 7, 2026.

What we collect

We do not collect personal data ourselves. There are no sign-ups, comments or forms on the site.

Hosting

The site is hosted on GitHub Pages. GitHub may process technical data such as your IP address and browser details when you load a page. See the GitHub Privacy Statement.

Fonts

The home page loads fonts from Google Fonts, so your browser sends a request to Google servers when it opens that page. See Google's privacy policy.

External links

Stories link to publishers such as CNBC, MarketWatch and Bloomberg. Those sites have their own privacy practices that we do not control.

Changes

If we add analytics, advertising, a newsletter or anything else that handles personal data, this page will be updated before that change goes live.
